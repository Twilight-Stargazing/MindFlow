# MindFlow
🧠 MindFlow

Tiếng Việt | English

MindFlow là ứng dụng desktop tạo sơ đồ tư duy (mind map) với giao diện tiếng Việt gọn nhẹ. Bạn có thể bắt đầu từ một sơ đồ trống hoặc từ các template có sẵn, rồi tự do thêm nhánh, chỉnh chữ và màu sắc. Ứng dụng dành cho tất cả mọi người.

✨ Tính năng
🏠 Trang chủ
Sơ đồ mới: bắt đầu từ một chủ đề trống.
Mở file: mở file .mmap có sẵn trên máy.
Gần đây: danh sách các file đã mở gần đây. File đã bị xóa khỏi máy sẽ không hiện trong danh sách.
Template có sẵn:
Brainstorm: gom ý tưởng quanh một vấn đề.
Kế hoạch dự án: mục tiêu, công việc, thời gian, nhân sự.
Ghi chép bài học: khái niệm, ví dụ và câu hỏi còn lại.
SWOT: điểm mạnh, yếu, cơ hội, thách thức.
Kế hoạch tuần: ưu tiên, công việc, lịch hẹn.
🌿 Soạn sơ đồ
Thêm nhánh con hoặc nhánh cùng cấp.
Sửa chữ trong node, xóa node.
Hoàn tác và làm lại.
Định dạng chữ: in đậm, in nghiêng, màu chữ.
Đổi màu ô (node); nút Mặc định đưa màu ô về lại như ban đầu.
Thu phóng sơ đồ, có nút Vừa khung để vừa với cửa sổ.
Một số phím tắt (sẽ bổ sung thêm).
💾 Lưu và chia sẻ
Lưu sơ đồ vào file .mmap, định dạng riêng của MindFlow.
Hỗ trợ OPML trên thanh công cụ.
Tải sơ đồ lên cloud (cần kết nối mạng).
✨ Glint
Thanh giờ và ngày nổi, dùng chung với Focus Wind.
💻 Yêu cầu hệ thống
Dành cho Windows.
Viết bằng Python và pywebview.
Dùng khoảng 50–100 MB RAM.
Hoạt động offline. Chỉ cần mạng khi tải sơ đồ lên cloud hoặc kiểm tra cập nhật.
📥 Cài đặt

Vào trang Releases và tải bộ cài hoặc file .exe.

🗂️ Cấu trúc mã nguồn
main.py: phần chính của ứng dụng.
ui/index.html: giao diện.
🗺️ Kế hoạch
Xuất sơ đồ ra thêm nhiều định dạng khác.
Bổ sung thêm phím tắt.
🤝 Đóng góp

Mọi góp ý và báo lỗi đều được chào đón. Bạn có thể mở Issue hoặc gửi Pull Request.

🧠 MindFlow (English)

Tiếng Việt | English

MindFlow is a desktop mind-mapping app with a lightweight Vietnamese interface. Start from a blank map or a built-in template, then freely add branches and adjust text and colours. It is made for everyone.

✨ Features
🏠 Home
New map: start from an empty topic.
Open file: open an existing .mmap file on your computer.
Recent: a list of recently opened files. Files that have been deleted no longer appear.
Built-in templates:
Brainstorm: collect ideas around a problem.
Project plan: goals, tasks, timeline, people.
Study notes: concepts, examples and open questions.
SWOT: strengths, weaknesses, opportunities, threats.
Weekly plan: priorities, tasks, appointments.
🌿 Editing
Add child or sibling nodes.
Edit text inside a node, delete nodes.
Undo and redo.
Text formatting: bold, italic, text colour.
Change node colour; the Default button restores the original node colour.
Zoom in and out, with a Fit to view button.
A few keyboard shortcuts (more to come).
💾 Saving and sharing
Save maps to .mmap files, MindFlow's own format.
OPML support in the toolbar.
Upload maps to the cloud (requires an internet connection).
✨ Glint
A floating time and date bar, shared with Focus Wind.
💻 Requirements
Made for Windows.
Built with Python and pywebview.
Uses about 50–100 MB of RAM.
Works offline. An internet connection is only needed to upload maps to the cloud or check for updates.
📥 Installation

Go to the Releases page and download the installer or the .exe file.

🗂️ Source layout
main.py: the main application.
ui/index.html: the interface.
🗺️ Roadmap
Export maps to more formats.
Add more keyboard shortcuts.
